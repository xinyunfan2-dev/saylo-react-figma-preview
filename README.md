# Saylo React Figma Preview

A static React + Vite prototype for the Saylo iOS UI direction: Home, Hermes preset creation, and Profile. Includes light/dark themes, Liquid Glass navigation, and yellow/purple accents.

## Open in Figma Make

Use Figma Make desktop Beta and choose **Open a folder** for this repository, or download and extract `saylo-react-ui-figma.zip`. The project includes `.figma/make` setup scripts.

To copy a rendered screen into a Figma Design file, open the desired state in the Make preview and use **Copy design**.

## Run locally

```sh
npm ci
npm run dev
```

All account, usage, and history content is sample data. The prototype uses browser-local storage and has no backend credentials or secrets.
